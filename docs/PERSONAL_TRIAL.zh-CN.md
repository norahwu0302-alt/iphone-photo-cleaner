# iPhone 相册整理：个人测试版

这个项目基于 [TidyByte](https://github.com/360ghar/tidybyte)，保留原项目的 MIT 许可证。个人测试版用于在 Windows 配合云端编译后，安装到自己的 iPhone，验证重复检测、相似照片和内容分类。

## 本次修改

- 独立的个人构建，不使用原作者的开发者账号、应用标识或 App Group。
- 不包含桌面小组件。语言和设置保存在 App 自己的空间。
- 保留现有的中文界面、照片权限提示、重复检测、相似照片、内容分类和相簿功能。
- 相似度和分类算法沿用上游，尚需在你的真实图库中验证。

## 需要准备

- iOS 17 或更新版本的 iPhone。
- Windows 电脑和可以连接手机的数据线。
- 自己的 Apple 账号。账号登录和验证码在安装工具里由你本人完成，不需要发到聊天里，也不上传到 GitHub。
- [Sideloadly 官方 Windows 安装器](https://sideloadly.io/)。按官网要求准备 Apple 驱动及 iTunes/iCloud 组件；不要仅为安装而卸载已有软件，遇到冲突先核实。

## 安装

1. 下载云构建生成的 IPA 压缩包，解压出 `.ipa`。这是未签名的真机安装包，不能直接在 iPhone 上点开安装。
2. 在 Windows 安装并打开 Sideloadly，用数据线连接已解锁的 iPhone；手机出现提示时选择信任这台电脑。
3. 将 `.ipa` 放入 Sideloadly，选择自己的手机，输入自己的 Apple 账号并按提示完成签名安装。
4. 如果手机提示开发者未受信任，在“设置 → 通用 → VPN 与设备管理”中处理自己的开发者条目；如要求开发者模式，按 iPhone 的系统提示完成。
5. 打开 `TidyByte Test`。手机为简体中文时界面会跟随系统；也可以在 App 设置中切换语言。

免费 Apple 账号的签名通常 7 天到期。可在 Sideloadly 设置自动续签，但电脑需要运行该工具，并能通过 USB 或已配置的同一 Wi-Fi 发现手机。续签同一个安装包不需要重新编译代码。

## 首轮验证：先用少量照片

先授权一小组包含重复副本、相似连拍和不同内容的照片。有限访问只分析你选中的项目；后续再扩大授权范围。

1. **重复检测**：看重复组是否正确。精确重复工具可能预先勾选非最佳、非收藏副本，删除前先检查；第一次可只扫描，不提交删除。
2. **相似照片**：查看同一场景的照片是否合理分组，试着调整敏感程度。相似不代表没有保留价值。
3. **内容分类**：查看食物、宠物、风景、文档等分类，并记录错分或漏分。内容分类与自动创建系统相簿是不同功能，不要假设扫描后已建好所有相簿。
4. **相簿**：选少量照片加入一个测试相簿，在苹果“照片”App 中检查是否出现。
5. **删除与恢复**：只选择一个自己确认不需要的测试副本，检查系统删除确认；取消时照片应保留。若确认删除，可到苹果“照片 → 最近删除”检查并恢复。

扫描不会自行执行删除。某些单组删除只出现系统确认，批量操作还可能出现 App 内确认。收藏不等于永久保护：手动选择和部分全选操作仍可能选中收藏照片。

## 已知边界

- 精确重复检测会跳过仅在 iCloud 中、没有本地原件的照片；一次扫描没有结果不代表整个图库没有重复。
- 启用 iCloud 照片时，删除会同步到其他设备。“最近删除”通常保留 30 天；试用时不要清空它。
- 自然语言搜索依赖支持的 iOS/设备和本机模型是否可用。基础重复检测与内容分类不要求你提供第三方 AI API 密钥。
- 云端处理的是项目源码和安装包；照片识别在手机上执行。iCloud 照片获取仍可能使用手机网络。
- 云编译成功和模拟器测试通过，不等于真机的准确率、速度和安装已验证。

## 开发者复现

个人构建入口是 `project.personal.yml` 和 `scripts/personal/build.sh`，云端入口是 GitHub Actions 的 `personal-ipa.yml`。构建需 macOS、Xcode 26 或更新版本与 XcodeGen；Windows 负责编辑源码及安装 IPA。

原项目的 `project.yml` 和上游 CI 保持独立。个人构建必须定义 `PERSONAL_BUILD`，否则会尝试使用上游的 App Group 存储。
